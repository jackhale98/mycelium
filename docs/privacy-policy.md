# Privacy Policy for Mycelium

**Last updated: 21 August 2026**

Mycelium does not collect, transmit, or share any personal data.

## What Mycelium stores

Mycelium reads and writes plain-text Org files in a folder you choose. Those
files stay where you put them — on your device, or in whatever folder you
selected through your file provider or git client. Mycelium never uploads them.

To make searching fast, Mycelium keeps an index of your notes in its own private
app storage. The index is derived entirely from your files and never leaves the
device. Deleting the app deletes the index.

Mycelium also stores two small preferences: which folder you chose (as a
security-scoped bookmark, so it can reopen it), and your display settings such
as theme and TODO keywords.

## What Mycelium does not do

- No account, sign-in, or user identifier
- No analytics, telemetry, crash reporting, or advertising
- No third-party SDKs
- No network requests of any kind — the app has no server component

Because Mycelium makes no network requests, there is no data for us or anyone
else to receive. We cannot see your notes.

## Permissions

Mycelium asks for access to one folder, which you pick yourself using the system
file picker. It uses that access only to read and write the Org files in that
folder. You can revoke it at any time through your operating system, or by
choosing a different folder in the app.

## Children

Mycelium is a note-taking tool suitable for all ages. It collects no data from
anyone, including children.

## Changes

If this policy changes, the updated version will be published here and the date
above revised.
